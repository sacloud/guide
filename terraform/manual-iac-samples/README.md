# さくらクラウド Terraform 構成例集

このリポジトリは、さくらクラウドで様々なインフラストラクチャパターンを構築するためのTerraform構成例を提供します。各ディレクトリには、特定のユースケースに最適化された実践的な構成が含まれています。

## 📋 構成例一覧

### [01 - マルチリージョン災害復旧構成](./01/)
**概要**: 複数リージョンにまたがる高可用性Webアプリケーション環境

**主な特徴:**
- 柔軟なリージョン選択（プライマリ・セカンダリ）
- GSLBによるグローバルロードバランシング
- マネージドデータベースのマスター・スレーブ構成
- ブリッジ接続によるリージョン間プライベート通信
- 自動フェイルオーバー機能

**適用シーン:**
- ミッションクリティカルなWebアプリケーション
- 災害復旧（DR）環境の構築
- 地理的冗長性が必要なシステム

### [02 - オートスケール構成](./02/)
**概要**: 負荷に応じた自動スケーリングWebアプリケーション環境

**主な特徴:**
- CPU・ネットワーク使用量ベースの自動スケーリング
- エンハンスドロードバランサーによる高性能負荷分散
- スケジュールベース運用（平日業務時間対応）
- 初期サーバーディスククローン機能
- カスタムディスクまたは既存ディスクからの構築

**適用シーン:**
- トラフィック変動の大きいWebサービス
- コスト効率を重視するシステム
- 時間帯による負荷変動があるサービス

### [03 - セキュアWebアプリケーション構成](./03/)
**概要**: パケットフィルタとVPN機能を持つセキュアなWebアプリケーション環境

**主な特徴:**
- 詳細なパケットフィルタリング（Web・DB層の分離）
- VPCルーターによるL2TP/IPSec + WireGuard VPN
- IPアドレスリストによるアクセス制御
- プライベートネットワーク限定のデータベース
- 多層セキュリティ設計

**適用シーン:**
- セキュリティが重要なWebアプリケーション
- リモートワーク環境の構築
- 機密情報を扱うシステム

### [04 - VPCゲートウェイ構成（NFS + Sambaファイルサーバー）](./04/)
**概要**: VPCルーターをゲートウェイとしたセキュアなファイル共有環境

**主な特徴:**
- VPCルーターによるインターネットゲートウェイ
- サーバーは直接インターネットアクセス不可（プライベートのみ）
- Cloud-initによるNFS・Samba自動セットアップ
- L2TP/IPSec + WireGuard VPNアクセス
- 柔軟なネットワークCIDR設定

**適用シーン:**
- セキュアなファイル共有環境
- 社内ファイルサーバーの構築
- プライベートクラウドストレージ

### [05 - セキュアマルチリージョン分散システム](./05/)
**概要**: Sophos Firewallを使用したマルチリージョンセキュリティシステム

**主な特徴:**

## 🚀 クイックスタート

### 1. 前提条件
- Terraform >= 1.0
- さくらクラウド APIキーの取得
- Terraform Provider `sacloud/sakura` v3

### 2. 環境変数設定
```bash
export SAKURA_ACCESS_TOKEN="your-access-token"
export SAKURA_ACCESS_TOKEN_SECRET="your-access-token-secret"
```

`SAKURACLOUD_` プレフィックスの環境変数も互換性のため引き続きサポートされていますが、新しい設定では `SAKURA_` プレフィックスを使用してください。

v3では、サーバー、データベース、VPNルーターのパスワードを `password_wo` と `password_wo_version` で設定します。サンプルのパスワード変数名は従来どおりです。

### 3. 構成例の利用
```bash
# 希望する構成例のディレクトリに移動
cd 01/

# サンプル設定をコピー
cp terraform.tfvars.example terraform.tfvars

# 設定ファイルを編集
nano terraform.tfvars

# Terraform実行
terraform init
terraform plan
terraform apply
```

## 🛠️ カスタマイズガイド

### 共通設定項目
- **リージョン選択**: is1a（石狩）、tk1a（東京）、tk1b（東京）など
- **サーバースペック**: CPU（1-32コア）、メモリ（1-128GB）
- **ディスク**: サイズ（20-4000GB）、タイプ（SSD/HDD）
- **OS選択**: Linux各種、Windows Server

### セキュリティ強化オプション
- **パケットフィルタ**: IPアドレス・ポート単位の制御
- **VPN**: L2TP/IPSec、WireGuard
- **プライベートネットワーク**: CIDR設定可能
- **アクセス制御**: IPアドレスリスト

### 高可用性オプション
- **マルチリージョン**: 地理的冗長性
- **ロードバランサー**: L4/L7負荷分散
- **データベース冗長化**: マスター・スレーブ構成
- **オートスケール**: 負荷ベース自動スケーリング
