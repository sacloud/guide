# さくらクラウド構成例 05 - セキュアマルチリージョン分散システム

このTerraform構成は、さくらクラウドで2つのリージョンにまたがるセキュアな分散システムを構築します。監視ゾーンにVPNアクセス拠点を配置し、業務運用ゾーンではUTMサーバーをインターネットゲートウェイとして、高いセキュリティを実現します。

## 主な機能

- **柔軟なマルチリージョン構成**: リージョンを変数で指定可能
- **セキュアゾーン分離**: 監視ゾーンと業務運用ゾーンの完全分離
- **UTMゲートウェイ**: 業務ゾーンのインターネット接続をUTMで一元管理
- **VPN集約拠点**: 監視ゾーンでのVPNアクセス管理
- **ブリッジ接続**: リージョン間セキュアプライベートネットワーク
- **統合認証**: Windows認証サーバーによる一元管理
- **データベース**: プライベートネットワーク限定データベース

## 構成要素

### 監視ゾーン（リージョン可変: デフォルトis1a）

#### VPCルーター（VPN集約拠点）
- **プラン**: standard
- **役割**: システム全体へのVPNアクセス拠点
- **機能**: L2TP/IPSec VPNサーバー
- **VPN IPプール**: 192.168.0.240-249
- **ネットワーク**: グローバルIP + プライベートIP (192.168.0.1)

#### 監視サーバー
- **OS**: Windows Server 2022
- **役割**: システム全体の監視・管理
- **スペック**: 1コア、4GBメモリ
- **ディスク**: 100GB SSD
- **ネットワーク**: プライベートIP (192.168.0.11) のみ
- **アクセス**: VPN経由でのみアクセス可能

### 業務運用ゾーン（リージョン可変: デフォルトtk1a）

#### UTMサーバー（インターネットゲートウェイ）
- **OS**: Sophos Firewall
- **役割**: 業務ゾーン全体のインターネットゲートウェイ
- **機能**: 統合脅威管理（ファイアウォール、IDS/IPS、アンチウイルス、Web フィルタリング、NAT）
- **スペック**: 2コア、4GBメモリ
- **ディスク**: 100GB SSD
- **ネットワーク**: WAN（グローバルIP）+ LAN（プライベートIP 192.168.1.1）
- **特徴**: 業務ゾーン唯一のインターネット接続点、企業級セキュリティ機能


#### 認証管理サーバー
- **OS**: Windows Server 2022
- **役割**: Active Directory、認証管理
- **スペック**: 1コア、4GBメモリ
- **ディスク**: 100GB SSD
- **ネットワーク**: プライベートIP (192.168.1.12) のみ
- **インターネット接続**: UTMサーバー経由のみ

#### 業務運用サーバー
- **OS**: Windows Server 2022
- **役割**: 業務アプリケーション実行
- **スペック**: 1コア、4GBメモリ
- **ディスク**: 100GB SSD
- **ネットワーク**: プライベートIP (192.168.1.13) のみ
- **インターネット接続**: UTMサーバー経由のみ

#### データベースアプライアンス
- **種別**: マネージドMySQL/MariaDB
- **プラン**: 90GB
- **ネットワーク**: プライベートIP (192.168.1.21) のみ
- **アクセス制御**: 192.168.1.0/24からのみ接続可能
- **バックアップ**: 毎日02:00自動実行
- **インターネット接続**: なし（完全プライベート）

### ネットワーク構成

#### プライベートスイッチ
- **監視スイッチ**: 石狩リージョン (192.168.0.0/24)
- **業務スイッチ**: 東京リージョン (192.168.1.0/24)

#### ブリッジ接続
- **接続方式**: リージョン間プライベート接続
- **帯域**: 共有
- **セキュリティ**: 完全分離されたプライベート通信

#### 追加IPブロック
- **用途**: 業務ゾーン用追加グローバルIP
- **サイズ**: /28 (16アドレス)
- **帯域**: 100Mbps

## 前提条件

- Terraform >= 1.0
- さくらクラウド API キーの設定
- 石狩と東京の両リージョンへのアクセス権限

### 環境変数の設定

**Linux/macOS:**
```bash
export SAKURA_ACCESS_TOKEN="your-access-token"
export SAKURA_ACCESS_TOKEN_SECRET="your-access-token-secret"
```

**Windows (PowerShell):**
```powershell
$env:SAKURA_ACCESS_TOKEN="your-access-token"
$env:SAKURA_ACCESS_TOKEN_SECRET="your-access-token-secret"
```

`SAKURACLOUD_` プレフィックスの環境変数も互換性のため引き続きサポートされていますが、新しい設定では `SAKURA_` プレフィックスを使用してください。

v3では、サーバー、データベース、VPNルーターのパスワードを内部で `password_wo` と `password_wo_version` により設定します。`server_password`、`db_password`、`vpn_password` の変数名は変更不要です。

## 設定オプション

### 基本設定
- `prefix`: リソース名プレフィックス（デフォルト: "example-08"）
- `monitoring_zone`: 監視ゾーンのリージョン（デフォルト: "is1a"）
- `business_zone`: 業務運用ゾーンのリージョン（デフォルト: "tk1a"）
- `server_password`: サーバールートユーザーのパスワード

### データベース設定
- `db_username`: データベースユーザー名（デフォルト: "dbuser"）
- `db_password`: データベースパスワード

### VPN設定（監視ゾーン）
- `vpn_pre_shared_secret`: VPN事前共有キー
- `vpn_username`: VPNユーザー名（デフォルト: "vpnuser"）
- `vpn_password`: VPNパスワード

## 使用方法

1. 変数ファイルの作成:
   ```bash
   cat > terraform.tfvars << EOF
   prefix = "my-system"
   monitoring_zone = "is1a"      # 監視ゾーンリージョン
   business_zone = "tk1a"        # 業務ゾーンリージョン
   server_password = "YourSecurePassword123!"
   db_username = "dbadmin"
   db_password = "DatabasePassword456!"
   vpn_pre_shared_secret = "VPNSecret789"
   vpn_username = "vpnuser"
   vpn_password = "VPNPassword123!"
   EOF
   ```

2. Terraform の初期化:
   ```bash
   terraform init
   ```

3. デプロイメントの計画:
   ```bash
   terraform plan
   ```

4. 設定の適用:
   ```bash
   terraform apply
   ```

- `monitoring_server_global_ip`: 監視サーバーのグローバルIP

### 業務運用ゾーン
- `utm_server_global_ip`: UTMサーバーのグローバルIP
- `utm_server_private_ip`: UTMサーバーのプライベートIP

## セキュリティ設計

### ネットワークセグメンテーション
1. **監視ゾーン**: 独立したネットワークセグメント (192.168.0.0/24)
2. **業務ゾーン**: 独立したネットワークセグメント (192.168.1.0/24)
3. **リージョン間通信**: ブリッジによるセキュアプライベート接続

### インターネットアクセス制御
1. **監視ゾーン**: VPCルーターのみがインターネットアクセス
2. **業務ゾーン**: UTMサーバーのみがインターネットアクセス
3. **業務サーバー群**: 全てUTMサーバー経由でのみインターネット接続
4. **データベース**: インターネットアクセス不可（完全プライベート）

### アクセス制御
1. **VPNアクセス**: 監視ゾーンのVPCルーターに集約
2. **業務ゾーン**: UTMによる統合脅威管理とゲートウェイ制御
3. **認証管理**: Active Directoryによる統合認証
4. **データベース**: プライベートネットワークからのみアクセス可能

### セキュリティ機能
1. **Sophos UTMゲートウェイ**: 統合脅威管理（ファイアウォール、IDS/IPS、アンチウイルス、Webフィルタリング、NAT）
2. **VPN集約**: 監視ゾーンでの一元的リモートアクセス管理
3. **ネットワーク分離**: ゾーンごとの完全分離
4. **高度脅威対策**: Sophos XG Firewallによる最新脅威対策

## 運用シナリオ

### シナリオ1: 通常運用
- 監視ゾーンから全システムの状態を監視
- 業務サーバーで業務アプリケーションを実行（UTM経由でインターネット接続）
- データベースへのアクセスは業務ゾーン内のみ（インターネットアクセス不可）

### シナリオ2: セキュアリモートアクセス
- 監視ゾーンのVPNサーバーに接続
- VPN経由でブリッジを通り業務ゾーンにアクセス
- 認証サーバーでユーザー認証後、業務サーバーで作業

### シナリオ3: セキュリティ監視・対応
- Sophos Firewallで業務ゾーンの全インターネット通信を監視・フィルタリング
- 監視サーバーでシステム全体のアラート検知
- 脅威検知時はSophos Firewallで高度なトラフィック制御・遮断
- WebブラウザでSophosの管理画面に直接アクセス可能

### シナリオ4: 障害・インシデント対応
- VPN経由での安全な管理アクセス
- Sophos Firewallの詳細ログでインシデント分析
- リアルタイム脅威インテリジェンスによる自動対応
- ブリッジ接続による両ゾーン間での情報共有

## Sophos Firewall管理

### 初期セットアップ
1. **管理画面アクセス**: `https://<UTMサーバーのグローバルIP>:4444`
2. **初期認証**: admin / admin（初回ログイン後要変更）
3. **ライセンス**: Sophosアカウントでライセンス認証
4. **ネットワーク設定**: WAN（インターネット）とLAN（プライベート）インターフェース設定

### 主要設定項目
1. **ファイアウォールルール**: LANからWANへの通信許可設定
2. **NAT設定**: プライベートネットワークからのインターネットアクセス
3. **Webフィルタリング**: 不適切サイトのブロック設定
4. **IPS設定**: 侵入防止システムの有効化
5. **アンチウイルス**: リアルタイムスキャン設定

### 監視・ログ
- **ライブログ**: リアルタイム通信監視
- **レポート**: セキュリティ状況の定期レポート
- **アラート**: 脅威検知時の自動通知設定

## VPN接続設定

### Windows
1. 設定 → ネットワークとインターネット → VPN
2. VPN接続を追加
3. 以下を設定:
   - サーバー名: VPCルーターのグローバルIP
   - VPN の種類: L2TP/IPSec（事前共有キー）
   - 事前共有キー: 設定した値
   - ユーザー名とパスワード: 設定した値

### macOS
1. システム環境設定 → ネットワーク
2. 「+」でVPN (L2TP) を追加
3. サーバーアドレスとアカウント名を入力
4. 認証設定で事前共有キーとパスワードを設定

### Linux
```bash
# strongswan と xl2tpd をインストール
sudo apt-get install strongswan xl2tpd

# 設定ファイルを編集
sudo nano /etc/ipsec.conf
sudo nano /etc/xl2tpd/xl2tpd.conf
sudo nano /etc/ppp/options.l2tpd.client
```

## トラブルシューティング

### 接続問題
1. **リージョン間通信不可**: ブリッジの状態確認
2. **VPN接続失敗**: 事前共有キー、認証情報の確認
3. **データベース接続不可**: アクセス許可ネットワークの確認

### パフォーマンス問題
1. **遅延**: リージョン間の物理距離による遅延を考慮
2. **帯域**: 追加IPブロックの帯域制限（100Mbps）を確認
3. **リソース**: サーバースペックの見直し

### セキュリティアラート
1. **Sophos Firewallアラート**: Web管理画面でリアルタイム脅威分析と対策実施
2. **認証失敗**: Active Directoryのログ確認
3. **不正アクセス**: Sophosファイアウォールルールの見直し
4. **マルウェア検知**: Sophosアンチウイルス機能による自動隔離・駆除

## ベストプラクティス

1. **定期バックアップ**: データベースの自動バックアップ確認
2. **セキュリティ更新**: Windows Update、Sophos Firewall自動更新の定期確認
3. **監視強化**: 監視サーバーでのアラート設定
4. **アクセス管理**: VPNアカウントの定期的な見直し
5. **ログ管理**: 各サーバーのログを監視サーバーに集約
6. **災害対策**: リージョン障害を想定した復旧計画

この構成により、地理的に分散した高可用性システムを構築できます。監視と業務の分離により、セキュアで管理しやすい環境を実現します。
